# Folyo para Mac

Aquí se publican las versiones de [Folyo](https://www.getfolyo.app), la app que encuentra las facturas de tu correo y las ordena para tu gestoría.

**Descarga:** [getfolyo.app](https://www.getfolyo.app) o directamente la [última versión](https://github.com/ptordera/folyo-releases/releases/latest/download/Folyo.dmg).

Cada versión está firmada con Developer ID y notarizada por Apple. La app se actualiza sola.
